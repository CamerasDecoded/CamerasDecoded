Custom button map

Which functions belong on the a7C II's custom buttons?

camerasdecoded.com/camera-select/sony/a7c-ii/custom-buttons
The answer — share this
Focus Area on Custom Button 1, Recognition Target on Custom Button 2, Auto Framing on the movie map — the three changes you make mid-shoot, under fingers that already know where they are.
Assign: Setup → Operation Customize → Custom Key/Dial Set.  ·  Button 1: Focus Area  ·  Button 2: Recognition Target  ·  Movie map: Auto Framing  ·  Save: Camera Set. Memory → 1
Cameras Decoded — Camera Select
The map

Two maps: stills and movie

MENU→Setup→Operation Customize→Custom Key/Dial Set.

Sony gives stills and movies separate assignment sets in the same menu. Build both — a key set for stills does nothing for you the day you switch to video. Button 1: Focus Area. Button 2: Recognition Target. Movie map: Auto Framing. Note the absence: this body has no joystick to assign.

Assignment 1

Button 1 — Focus Area

The area change is the most common mid-shoot move there is: portrait to action, Spot to Tracking. Buried in the Focus menu it costs you the moment; on a button it costs one press.

Assignment 2

Button 2 — Recognition Target

MENU→Focus→Subject Recognition→Recognition Target

The AI unit is only aimed when the target is named. One press switches Human to Bird to Animal as the subject changes — no menu dive while the moment leaves.

Assignment 3

Movie map — Auto Framing

MENU→Shooting→Shooting Option→Auto Framing Settings

For solo video, Auto Framing crops and follows you in frame. It is a movie and streaming tool only — which is why it belongs on the movie map, not crowding the stills one.

Save it

The map lives in Memory 1

MENU→Shooting→Shooting Mode→Camera Set. Memory

Button assignments are part of a registered setup. Save the finished map to slot 1, and the mode dial restores your settings and your keys together.

Try it now

Assign Custom Button 1 → Focus Area, then shoot for a day before adding the rest. Muscle memory is built one key at a time.
