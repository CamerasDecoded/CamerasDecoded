First Setup

What should you change on a brand-new Sony FX3 before your first shoot — two slots that both take CFexpress Type A and SD, RAW with no Lossless Comp option, and a Cinema Line body with no viewfinder and no mode dial?

The answer — share this
Format both cards in the camera — each slot takes CFexpress Type A and SD, so match the card to the codec before you roll — shoot RAW at Uncompressed or Compressed (this body has no Lossless Comp option), set Rec. Media so stills and movies land where you want them, know the body's shape (no viewfinder, no mode dial, mechanical shutter to 1/8000, flash sync 1/250), then save the whole setup to M1–M4.
Format: MENU → Shooting → Media → Format  ·  Slots: both take CFexpress Type A + SD  ·  RAW File Type: Uncompressed / Compressed only  ·  Flash sync: 1/250  ·  Save: MENU → Shooting → Shooting Mode → Camera Set. Memory (M1–M4)

Step 1

Format both cards in the camera

MENU→Shooting→Media→Format

Formatting builds the folder structure the camera expects. Both slots take CFexpress Type A and SD (UHS-I/UHS-II) — Slot 1 is the default, and the card goes in label-to-monitor for CFexpress, terminal-to-monitor for SD. Pick Format, choose the slot, press Enter for a quick format; for a full format, press the Delete button on the format screen. The card choice is a codec decision: XAVC S-I 4K at 600 Mbps needs CFexpress Type A VPG200+ or an SDXC V90 card, and slow-motion S-I 4K at 1200 Mbps needs CFexpress Type A VPG200+ only — no SD card qualifies. Formatting erases everything on the card, including protected images and the M1–M4 settings stored on it. Shortcut: hold MENU, then the Delete button, for about two seconds on the shooting screen.

Step 2

Shoot RAW, at full quality

MENU→Shooting→Image Quality/Rec→Image Quality Settings→File Format

Set File Format to RAW, then pick the RAW File Type — and here this body differs from every Sony stills camera around it: the choice is Uncompressed or Compressed only. There is no Lossless Comp option on the FX3. Compressed is about half the size of Uncompressed, with quality traded away; Uncompressed is the full file. RAW on this body is 14-bit, and the RAW aspect is always 3:2. Note the path too: File Format lives under an extra Image Quality Settings submenu, one level deeper than the stills bodies. Creative Look is the JPEG palette — ST, PT, NT, VV, VV2, FL, IN and more, plus Custom Looks — each adjustable for contrast, highlights, shadows, fade, saturation, sharpness and clarity. RAW keeps everything; the Look shapes the JPEG.

Step 3

Decide where the files land

MENU→Shooting→Media→Rec. Media Settings→Recording Media

With two slots, the split is yours to choose. For stills: Slot 1, Slot 2, Simult. Recording (the same image to both cards — the backup), or Sort Recording (RAW to one slot, JPEG or HEIF to the other — the working split). For movies: Slot 1, Slot 2, or Simult. Recording. Slot 1 is the default for both. Two details worth knowing: the RAW File Type is the same on both slots even under Sort Recording — you cannot record Uncompressed to one card and Compressed to the other — and the Memory/Recall Media setting in the same group picks which slot your M1–M4 setups live on.

Step 4

Know the body

MENU→Shooting→Shooting Mode→Shoot Mode

Four facts shape how you shoot this camera. There is no viewfinder — the 3.0-inch touch LCD (1.44 million dots) is the only way to see the frame. There is no mode dial — the MODE button opens the shooting-mode list: stills modes (Intelligent Auto, P/A/S/M), movie modes, and the M1–M4 recall slots. The shutter, though, is a real one: a mechanical focal-plane shutter, 1/8000 to 30 seconds plus BULB, with a flash sync speed of 1/250s — eight times faster than the vlog bodies’ 1/30, because the shutter is mechanical. Burst runs to 10 fps (Hi+). And the body carries a built-in cooling fan, because this camera is built to record long takes, not short clips.

Step 5

Save the setup to memory

MENU→Shooting→Shooting Mode→Camera Set. Memory

Register everything you just built with Camera Set. Memory: M1 through M4 live on the memory card — recall them any time from the MODE button's registration recall modes, and remember that formatting the card erases them. Memory/Recall Media picks which slot the sets live on. Then confirm the firmware under Setup → Setup Option → Version — current is 7.02 (March 2026). The 7.00 line brought the BIG6 home screen, external Blackmagic RAW recording, and anamorphic de-squeeze. One trap from Sony's own release notes: updating from Ver. 2.02 or earlier requires updating to Ver. 2.04 or Ver. 2.05 first, then to 7.x — skip that step and the update errors out. Update with 51% battery or more.

Try it now

Do the steps now, in order, then save the setup with Camera Set. Memory — one set to M1 — and recall it from the MODE button to prove it returns. Finish by checking the firmware — current is 7.02 — and pairing the Creators' App.
