Custom button map

Which functions belong on the a7 IV’s custom buttons?

The map — rear of camera
Step 1

Open the right menu

MENU→Setup→Operation Customize→Custom Key/Dial Set.

Sony gives stills and movies separate button maps — the same button can do one job for photos and another for video. Set the stills map first, then copy the logic to the movie map.

The answer — share this
Focus Area on C3, Face/Eye Subject on C4, Zebra on AEL — the three changes you make mid-shoot, under fingers that never leave the grip.
Path for all of it: Setup → Operation Customize → Custom Key/Dial Set.  ·  Stills and movie get separate maps — set both.
Cameras Decoded — Camera Select
Step 2

C3 — Focus Area

Assign: Focus Area. Your Focus Area Limit list (Autofocus lesson) is short, so this button becomes a fast cycle: Tracking: Zone, Zone, Spot. One press, one turn of the wheel, done — no menu.

Step 3

C4 — Face/Eye Subject

Assign: Face/Eye Subject. People, then a dog runs in, then a bird lands. This button switches what the eye detection is trained on without opening the Focus menu.

Step 4

AEL — Zebra Display

Assign: Zebra Display. AEL’s factory job (locking exposure) is one most hybrid shooters rarely press. Zebra is one you want constantly when video enters the picture — highlights checked in one press, in stills and movie alike.

Step 5

Save the map into Memory

MENU→Shooting→Shooting Mode→Camera Set. Memory

Button assignments are part of a registered memory set. Save the finished map to the same Memory 1 as your First Setup, so the map survives a reset and travels to any a7 IV you pick up.

Try it now

Assign C3 only, then shoot for ten minutes switching focus areas by button instead of menu. Add the rest when your hand starts reaching for them before your brain does.
