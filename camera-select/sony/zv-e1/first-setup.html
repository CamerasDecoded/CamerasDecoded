First Setup

What should you change on a brand-new Sony ZV-E1 before your first shoot — one SD slot, RAW without size letters, SteadyShot for manual glass, and a body with no viewfinder and no mechanical shutter?

The answer — share this
Format the single SD card in the camera — it is the only copy of everything on it — shoot RAW at Lossless Comp (no size letters on this body), turn SteadyShot on and set the focal length by hand for manual glass, know the body's shape (no viewfinder, electronic shutter only, flash sync 1/30), then save the whole setup with Camera Set. Step 1

Format the card in the camera

MENU→Shooting→Media→Format

Formatting builds the folder structure the camera expects. The ZV-E1 has one SD card slot (UHS-II) — no second slot, no CFexpress, no backup copy. The card you format is the only copy of everything on it, so empty it first. Pick Format, press Enter for a quick format; for a full format, press the Delete button on the format screen. Formatting erases everything on the card, including protected images and the M1–M4 settings stored on it. Buy the right speed: XAVC S-I 4K at 600 Mbps needs an SDXC V90 card, and 4K 120p needs V60 or better.

Step 2

Shoot RAW, at full quality

MENU→Shooting→Image Quality/Rec→File Format

Set File Format to RAW, then RAW File Type to Lossless Comp: full resolution, nothing thrown away, in a file well under an uncompressed one. RAW on this body is 14-bit, and the RAW aspect is always 3:2. Unlike the a7C II and a7 IV, there are no (L)/(M)/(S) size letters — the choice is simply Uncompressed, Lossless Comp, or Compressed (about half the size of Uncompressed, with quality traded away). Creative Look is the JPEG palette — ST, PT, NT, VV, VV2, FL, IN, SH, BW, SE, plus six Custom Looks — each adjustable for contrast, highlights, shadows, fade, saturation, sharpness and clarity. RAW keeps everything; the Look shapes the JPEG.

Step 3

Confirm SteadyShot is on

MENU→Shooting→Image Stabilization→SteadyShot

On for normal lenses — the 5-axis in-body system steadies stills and video. Shooting a fully manual lens? The camera cannot read its focal length, so open SteadyShot Adjust., switch to Manual, and set the Focal Length yourself (8–1000mm) — or stabilization works against you. Sony prints no CIPA stops figure for this body in the Help Guide specs, so do not expect a number. On a tripod, turn SteadyShot off; the manual warns it can cause malfunction when the camera is already steady. A lens with its own SteadyShot switch overrules this menu.

Step 4

Know the body

MENU→Shooting→Shooting Mode→Shoot Mode

Three facts shape how you shoot this camera. There is no viewfinder — the 3.0-inch vari-angle LCD is the only way to see the frame, which is why the screen flips fully forward for self-recording. The shutter is electronic only — there is no mechanical shutter at all, so the flash sync speed is 1/30s full-frame (1/60 in APS-C mode); faster than that and the flash clips. And there is no mode dial — a Still/Movie/S&Q switch on top chooses the shooting mode, and the exposure mode (P/A/S/M) is picked on screen. Burst shooting still runs to 10 fps (Hi+), and the electronic shutter is silent by nature.

Step 5

Save the setup to memory

MENU→Shooting→Shooting Mode→Camera Set. Memory

Register everything you just built with Camera Set. Memory: the body holds up to 3 sets per shooting mode (Still, Movie, S&Q, time-lapse each get their own three), and M1 through M4 live on the memory card — recall them any time from Shoot Mode → Cam.Set. A set saved to the card travels with the card to another ZV-E1 of the same model name. Then confirm the firmware under Setup → Setup Option → Version — current is 2.02 (November 11, 2025), which fixes a battery warning that lingered after charging and a camera that would not power on after USB streaming. Update with 51% battery or more; it takes about six minutes.

Try it now

Do the steps now, in order, then save the setup with Camera Set. Memory — one set in the body, one to the card — and recall it from Cam.Set to prove it returns. Finish by checking the firmware — current is 2.02 — and pairing the Creators' App.
