First Setup

What should you change on a brand-new Fujifilm X-T5 before your first shoot?

https://camerasdecoded.com/camera-select/fujifilm/x-t5/first-setup.html
THE ANSWER
Format both cards in the camera, give the second slot a job (BACKUP for paid work, SEQUENTIAL for room), shoot RAW at LOSSLESS COMPRESSED — the same data at a fraction of the size — set your film simulation, turn IS MODE on, then save the whole setup to CUSTOM 1.
Format: SET UP → USER SETTING → FORMAT · Card roles: SET UP → SAVE DATA SET-UP → CARD SLOT SETTING → BACKUP · RAW: IMAGE QUALITY SETTING → RAW RECORDING → LOSSLESS COMPRESSED · Save: IMAGE QUALITY SETTING → EDIT/SAVE CUSTOM SETTING → CUSTOM 1
Free lesson — the guided run walks every step.
STEP 1

Format both, then give slot 2 a job

MENU→SET UP→SAVE DATA SET-UP→CARD SLOT SETTING

Format each card in the camera (SET UP → USER SETTING → FORMAT). The X-T5 has two SD slots, both UHS-II. CARD SLOT SETTING gives the second slot a role: SEQUENTIAL (used only when slot 1 fills — the factory default), BACKUP (every picture recorded twice, once to each card), or SEPARATE (RAW to slot 1, JPEG or HEIF to slot 2 when shooting FINE+RAW). Client work wants BACKUP.

STEP 2

RAW, compressed without loss

MENU→IMAGE QUALITY SETTING→RAW RECORDING

Shoot FINE+RAW, and set RAW RECORDING to LOSSLESS COMPRESSED: Fujifilm’s reversible algorithm cuts files to about 30–90% of uncompressed size with no loss of image data. On a 64 GB card the manual’s table reads roughly 730 uncompressed RAW frames against 1,380 lossless. COMPRESSED is the lossy option — skip it.

STEP 3

Choose your palette on purpose

MENU→IMAGE QUALITY SETTING→FILM SIMULATION

Film simulation is the palette baked into every JPEG and HEIF: PROVIA/STANDARD is the neutral reference; Velvia, CLASSIC CHROME, CLASSIC Neg., the PRO Neg. pair and ACROS cover most work. REALA ACE — faithful color, hard tonality — was added by firmware 4.00; if it is missing from your list, update the body. RAW files keep everything, so FINE+RAW shooters can re-decide later.

STEP 4

IS on — then bank the setup

MENU→IMAGE QUALITY SETTING→EDIT/SAVE CUSTOM SETTING

Set IS MODE (SHOOTING SETTING) to CONTINUOUS or SHOOTING ONLY — a lens OIS switch overrules the menu. Then save the whole configuration: EDIT/SAVE CUSTOM SETTING creates banks CUSTOM 1 through CUSTOM 7, recalled with SELECT CUSTOM SETTING. There are no dial positions for banks on this body, and AUTO UPDATE CUSTOM SETTING on ENABLE will silently rewrite the bank you are using — leave it DISABLED unless that is what you want.

TRY IT NOW

Format both cards, set CARD SLOT SETTING to BACKUP, switch RAW RECORDING to LOSSLESS COMPRESSED, pick your default film simulation, and save it all as CUSTOM 1.
