Common fixes

What fixes the Fujifilm X-T5's known problems — detection that switches off, recording that stops, flash that won't fire?

https://camerasdecoded.com/camera-select/fujifilm/x-t5/common-fixes.html
THE ANSWER
Eye AF or subject detection “off”: the other system switched it off — they are mutually exclusive. Recording stopped: heat reached the AUTO POWER OFF TEMP. cutoff, or the card is below the bit rate's class. Flash dead: the electronic shutter is selected. A custom bank that keeps changing: AUTO UPDATE CUSTOM SETTING is on ENABLE.
Detection: AF/MF SETTING → FACE/EYE DETECTION SETTING / SUBJECT DETECTION SETTING (one at a time) · Heat: SET UP → POWER MANAGEMENT → AUTO POWER OFF TEMP. · Flash: SHOOTING SETTING → SHUTTER TYPE → MECHANICAL SHUTTER · Bank: IMAGE QUALITY SETTING → AUTO UPDATE CUSTOM SETTING → DISABLE

FIX 1

One system turns the other off

MENU→AF/MF SETTING→SUBJECT DETECTION SETTING

Subject detection and face/eye detection are mutually exclusive on this body: enabling SUBJECT DETECTION ON automatically sets FACE/EYE DETECTION to OFF, and the reverse holds too — the manual states it in both directions. Choose the system per subject, and keep both switches on function buttons.

FIX 2

Card first, then heat

MENU→SET UP→POWER MANAGEMENT→AUTO POWER OFF TEMP.

A stopped take has two documented causes. Card: 360 Mbps recording requires a V60 card or better; 100/200 Mbps require UHS Speed Class 3. Heat: the camera warns as temperature rises, then shuts down at the cutoff — AUTO POWER OFF TEMP. sets STANDARD or HIGH (HIGH extends recording; Fujifilm warns of low-temperature burns, so it is tripod work).

FIX 3

Blame the electronic shutter

MENU→SHOOTING SETTING→SHUTTER TYPE

On the electronic shutter the flash will not fire — a stated restriction, with pixel-shift multi-shot the only exception. Switch SHUTTER TYPE to MECHANICAL or E-FRONT CURTAIN and the flash returns, syncing at 1/250 s or slower. The electronic shutter also restricts sensitivity to ISO 125–12800 and disables long-exposure noise reduction.

FIX 4

Auto update is the culprit

MENU→IMAGE QUALITY SETTING→AUTO UPDATE CUSTOM SETTING

If CUSTOM 1 never matches what you saved, AUTO UPDATE CUSTOM SETTING is on ENABLE: changes to banks CUSTOM 1–7 apply automatically, so every experiment rewrites the active bank. Set DISABLE and save deliberately via EDIT/SAVE CUSTOM SETTING → SAVE THE CHANGES.

TRY IT NOW

Rehearse the fixes now: run the detection trade once, read your AUTO POWER OFF TEMP. setting, check SHUTTER TYPE before your next flash job, and set AUTO UPDATE CUSTOM SETTING to DISABLE.
