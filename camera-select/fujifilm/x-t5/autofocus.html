Autofocus, set up right

What are the right autofocus settings on the Fujifilm X-T5 — tracking, subject detection, eye AF?

https://camerasdecoded.com/camera-select/fujifilm/x-t5/autofocus.html
THE ANSWER
Put the focus lever on C for anything that moves and choose WIDE/TRACKING; name the subject exactly in SUBJECT DETECTION SETTING (animals means dogs and cats); pick the AF-C set that matches the motion; and remember the Fuji rule — subject detection and face/eye detection switch each other off.
Mode: focus selector → C · AF MODE: AF/MF SETTING → AF MODE → WIDE/TRACKING · Detection: AF/MF SETTING → SUBJECT DETECTION SETTING → SUBJECT DETECTION ON · Sets: AF/MF SETTING → AF-C CUSTOM SETTINGS
Free lesson — the guided run walks every step.
DECISION 1

The lever and the area

MENU→AF/MF SETTING→AF MODE

The front selector sets S, C or M. For movers: C, with AF MODE on WIDE/TRACKING so the whole frame can track; ZONE fences tracking into a movable area for predictable motion; SINGLE POINT (117 or the full 425 points) is for AF-S and still subjects. The focus stick moves the point; the rear command dial sizes it.

DECISION 2

Name the subject — exactly

MENU→AF/MF SETTING→SUBJECT DETECTION SETTING

Subject detection categories are literal: ANIMAL means dogs and cats; BIRD; AUTOMOBILE (car bodies and front ends); MOTORCYCLE&BIKE (the riders); AIRPLANE; TRAIN. There is no catch-all. A detected subject wears a white frame; subjects outside the list — horses, for one — are tracked honestly with WIDE/TRACKING instead.

DECISION 3

Sets, named for the motion

MENU→AF/MF SETTING→AF-C CUSTOM SETTINGS

AF-C CUSTOM SETTINGS: Set 1 Multi Purpose; Set 2 Ignore Obstacles & Continue to Track Subject; Set 3 for accelerating/decelerating subjects; Set 4 for suddenly appearing subjects; Set 5 for erratic movers. Set 6 Custom exposes Tracking Sensitivity, Speed Tracking Sensitivity and Zone Area Switching.

DECISION 4

Eye AF — and the trade

MENU→AF/MF SETTING→FACE/EYE DETECTION SETTING

For people: FACE DETECTION ON with EYE AUTO (or a right/left eye priority). The Fuji rule: subject detection and face/eye detection are mutually exclusive — enabling one automatically switches the other off, in both directions, exactly as the manual states. People or animals: one at a time.

TRY IT NOW

Set C + WIDE/TRACKING and track something crossing the frame; turn SUBJECT DETECTION ON for its category; then open FACE/EYE DETECTION SETTING and watch what the trade did.
