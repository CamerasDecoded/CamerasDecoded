Custom button map

Which buttons should you customize on the Fujifilm X-T5, and what belongs on each one?

https://camerasdecoded.com/camera-select/fujifilm/x-t5/custom-buttons.html
THE ANSWER
Keep Fn1 as your face detection switch, put SUBJECT DETECTION ON/OFF on Fn2 so the people-or-animals swap is one press each way, leave film simulation on its selector button, and give the rear dial's center SHUTTER TYPE — every assignment lives in FUNCTION (Fn) SETTING.
Path: SET UP → BUTTON/DIAL SETTING → FUNCTION (Fn) SETTING (or hold DISP/BACK) · Fn1: FACE DETECTION ON/OFF (factory) · Fn2: SUBJECT DETECTION ON/OFF · Selector Fn4: FILM SIMULATION (factory) · Rear dial center: SHUTTER TYPE
Pro lesson — the deep steps are in the guided run.
THE MAP

Know the factory map first

MENU→SET UP→BUTTON/DIAL SETTING→FUNCTION (Fn) SETTING

Assignments live at FUNCTION (Fn) SETTING, or hold DISP/BACK for the assignment screen. Factory defaults: Fn1 (front) = FACE DETECTION ON/OFF; Fn2 (front) = DRIVE SETTING; selector arrows Fn3 PHOTOMETRY, Fn4 FILM SIMULATION, Fn5 WHITE BALANCE, Fn6 PERFORMANCE; AFON = AF-ON; AEL = AE LOCK ONLY; Q = quick menu; rear dial center = FOCUS CHECK. If SELECTOR BUTTON SETTING is set to FOCUS AREA, the arrows move the focus point and Fn3–Fn6 are unreachable.

DEEP STEP 1

Build the detection swap

MENU→SET UP→BUTTON/DIAL SETTING→FUNCTION (Fn) SETTING

Subject detection and face/eye detection switch each other off on this body, so give the swap two front buttons: Fn1 keeps FACE DETECTION ON/OFF, Fn2 takes SUBJECT DETECTION ON/OFF. People or animals becomes one press each way. DRIVE SETTING loses nothing — the top-plate drive dial still does that job.

DEEP STEP 2

Two more that earn their place

MENU→SET UP→BUTTON/DIAL SETTING→FUNCTION (Fn) SETTING

SHUTTER TYPE belongs on a button (rear dial center): the electronic shutter silences the camera and unlocks its fastest speeds, but the flash will not fire on it. SELECT CUSTOM SETTING (or RECALL CUSTOM 1 SETTING) puts Fujifilm’s menu-buried banks on a control. FILM SIMULATION stays on Fn4, where Fujifilm already put it.

LIMITS

What the map survives

MENU→SET UP→BUTTON/DIAL SETTING→FUNCTION (Fn) SETTING

Button assignments are SET UP items; CUSTOM banks store shooting settings only. Recalling a bank never moves your buttons, so the map is built once and banks change underneath it. The assignable list also includes AF MODE, AF-C CUSTOM SETTINGS, RIGHT/LEFT EYE SWITCH, AF RANGE LIMITER, IS MODE and F-Log VIEW ASSIST.

TRY IT NOW

Hold DISP/BACK: set Fn2 to SUBJECT DETECTION ON/OFF and the rear dial center to SHUTTER TYPE, confirm SELECTOR BUTTON SETTING reads Fn BUTTON, then run the Fn1/Fn2 people-animals swap without lowering the camera.
