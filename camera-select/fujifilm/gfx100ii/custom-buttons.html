Custom button map

Which functions belong on the Fujifilm GFX 100 II's buttons — six front Fn buttons, a back row with a job each, three front command dials, and roles other systems don't offer?

camerasdecoded.com/camera-select/fujifilm/gfx100ii/custom-buttons
The answer — share this
Open SET UP → BUTTON/DIAL SETTING → FUNCTION (Fn) SETTING and build the map around this body's own roles: RIGHT/LEFT EYE SWITCH and AF-C CUSTOM SETTINGS for focus, RAW for the one-shot toggle, FILM SIMULATION for the look, and F IS MODE BOOST for video — on a surface that includes six front Fn buttons, a back row with a job each, and three front command dials you cycle by pressing the dial's center.
Path: SET UP → BUTTON/DIAL SETTING → FUNCTION (Fn) SETTING  ·  Fn1: FACE DETECTION ON/OFF  ·  Fn2: SUBJECT DETECTION ON/OFF  ·  Front dials: 3 + rear  ·  Q menu: separate stills and movie maps
Cameras Decoded — Camera Select
Step 1

FUNCTION (Fn) SETTING

MENU→SET UP→BUTTON/DIAL SETTING→FUNCTION (Fn) SETTING

FUNCTION (Fn) SETTING holds the assignment list — over sixty roles, from FILM SIMULATION and RAW to WAVEFORM/VECTORSCOPE, ZEBRA SETTING and COOLING FAN SETTING. The shipped defaults are worth learning first. Back of camera: AFON is AF-ON, the center of the rear command dial is FOCUS CHECK, Q opens the Quick Menu, AEL is AE LOCK ONLY. Front: Fn1 is FACE DETECTION ON/OFF, Fn2 is SUBJECT DETECTION ON/OFF, Fn3 is EXPO. COMP., Fn4 is SUB MONITOR MODE, Fn5 is PERFORMANCE, Fn6 is ELECTRONIC LEVEL SWITCH. The touch screen takes swipe gestures with assigned roles of their own.

Step 2

Count the surface

MENU→SET UP→BUTTON/DIAL SETTING→COMMAND DIAL SETTING

The assignable surface is larger than the labels suggest: six front Fn buttons, four back-of-camera function controls, touch gestures — and three front command dials plus a rear command dial. FRONT COMMAND DIAL 1 takes shutter speed (S.S. / PROGRAM SHIFT) or aperture; FRONT COMMAND DIAL 2, FRONT COMMAND DIAL 3 and the REAR COMMAND DIAL take shutter speed, aperture, exposure compensation, ISO, or NONE. Press the center of the front command dial to cycle DIAL 1 → 2 → 3; press and hold the center to open COMMAND DIAL SETTING. EXP. COMPENSATION ASSIGNMENT lets exposure compensation ride on the front dial, the rear dial, or both while the assigned function button is pressed.

Step 3

The working map

MENU→SET UP→BUTTON/DIAL SETTING→FUNCTION (Fn) SETTING

Build around this body's signature roles. RIGHT/LEFT EYE SWITCH swaps the tracked eye mid-shoot. AF-C CUSTOM SETTINGS changes tracking temperament without a menu dive. RAW toggles RAW on or off for a single shot — press once to add RAW to a JPEG-only setup, again to return. FILM SIMULATION puts the palette one press away. AF MODE and AF RANGE LIMITER shape the focus search. For video: F IS MODE BOOST changes the stabilization level while recording is in progress, WAVEFORM/VECTORSCOPE and ZEBRA SETTING put exposure tools on a button, F-Log VIEW ASSIST previews the grade, and COOLING FAN SETTING controls the optional fan. RECALL CUSTOM 1 SETTING jumps straight to a saved bank.

Step 4

Quick Menu, dials, save

MENU→SET UP→BUTTON/DIAL SETTING→EDIT/SAVE QUICK MENU

EDIT/SAVE QUICK MENU rebuilds the Quick Menu — with separate maps for stills and movies. When the map is built, save it with EDIT/SAVE CUSTOM SETTING to C1–C6 so the control scheme — buttons included — is recalled with the mode dial and survives a settings reset. AUTO UPDATE CUSTOM SETTING on ENABLE silently rewrites the bank you are using; leave it DISABLED unless that is what you want.

Try it now

Build the map now — eye switch, tracking, RAW toggle, film simulation — cycle the three front dials, press every assigned button once to prove it, then save the whole scheme to a Custom mode.
