First Setup

What should you change on a brand-new Fujifilm GFX 100 II before your first shoot — two different card slots, backup, 16-bit RAW and the film simulation palette, set once and saved to the dial?

camerasdecoded.com/camera-select/fujifilm/gfx100ii/first-setup
The answer — share this
Format both cards in the camera — a CFexpress Type B card in Slot 1, an SD card in Slot 2 — give the second slot a job (BACKUP for paid work, SEPARATE to split RAW and JPEG), shoot FINE+RAW at LOSSLESS COMPRESSED with 16-bit depth for stills, pick your film simulation, turn IS MODE on, then save the whole setup to a Custom mode on the dial: C1 through C6.
Slot 1: CFexpress Type B  ·  Slot 2: SD (UHS-II)  ·  Card roles: SET UP → SAVE DATA SET-UP → CARD SLOT SETTING → BACKUP  ·  RAW: IMAGE QUALITY SETTING → RAW RECORDING → LOSSLESS COMPRESSED, 16-bit  ·  Save: IMAGE QUALITY SETTING → EDIT/SAVE CUSTOM SETTING → C1–C6
Cameras Decoded — Camera Select
Step 1

CFexpress in 1, SD in 2

MENU→SET UP→USER SETTING→FORMAT

This body does not have two of the same slot: Slot 1 takes CFexpress Type B cards, Slot 2 takes SD, SDHC or SDXC (UHS-II). Format each card in the camera — the format dialog asks per slot. The split matters because the card decides what the camera can record: ProRes movies go to CFexpress cards only, 720 Mbps video needs CFexpress or a V90 SD card, 360 Mbps needs CFexpress or V60, and 100/200 Mbps needs UHS Speed Class 3 or better. The battery ships uncharged — charge the NP-W235 before first use.

Step 2

Give slot 2 a job

MENU→SET UP→SAVE DATA SET-UP→CARD SLOT SETTING

CARD SLOT SETTING offers three roles. SEQUENTIAL (the factory default) uses slot 2 only when slot 1 fills. BACKUP records every picture twice, once to each card — the working setting for anything paid. SEPARATE sends RAW files to slot 1 and JPEG or HEIF to slot 2, but only when IMAGE QUALITY is SUPER FINE+RAW, FINE+RAW or NORMAL+RAW. Set FRAME NO. to CONTINUOUS while you are here — it keeps file numbers climbing across cards instead of restarting at 0001. If the frame number ever reaches 999-9999, the shutter release disables itself until you insert a formatted card.

Step 3

The 102-megapixel file

MENU→IMAGE QUALITY SETTING→RAW RECORDING

Set IMAGE QUALITY to FINE+RAW — the JPEG to share, the RAW as the negative — and RAW RECORDING to LOSSLESS COMPRESSED: Fujifilm's reversible algorithm cuts files to about 30–90% of uncompressed size at 14-bit (45–100% at 16-bit) with no loss of image data. OUTPUT DEPTH offers 16-bit or 14-bit; 16-bit is available only in STILL IMAGE and PIXEL SHIFT MULTI SHOT drive modes, so bursts run 14-bit. COMPRESSED is the lossy option — skip it. SELECT JPEG/HEIF offers a 10-bit HEIF stills path (4:2:2, 10-bit) alongside JPEG.

Step 4

Choose your palette on purpose

MENU→IMAGE QUALITY SETTING→FILM SIMULATION

Film simulation is the palette baked into every JPEG and HEIF: PROVIA/STANDARD is the neutral reference; Velvia, ASTIA, CLASSIC CHROME, REALA ACE, the two PRO Neg. portrait palettes, CLASSIC Neg., NOSTALGIC Neg., ETERNA/CINEMA, ETERNA BLEACH BYPASS, ACROS and MONOCHROME (each with Ye/R/G filter variants) and SEPIA — twenty looks. RAW files keep everything, so FINE+RAW shooters can re-decide later. Film simulation settings for movies must be adjusted separately.

Step 5

Steady, fast, saved

MENU→IMAGE QUALITY SETTING→EDIT/SAVE CUSTOM SETTING

Set IS MODE (SHOOTING SETTING) to CONTINUOUS or SHOOTING ONLY — the system is rated up to 8.0 stops (CIPA, with the GF63mmF2.8), and a lens OIS switch overrules the menu. PERFORMANCE (POWER MANAGEMENT) offers BOOST — AF priority, EVF resolution priority, or EVF frame rate priority at 120P or 240P equivalent — against NORMAL for battery endurance (about 540 shots LCD, 460 EVF, CIPA). Then save the whole configuration: EDIT/SAVE CUSTOM SETTING creates banks C1 through C6, recalled by turning the mode dial — real dial positions on this body. AUTO UPDATE CUSTOM SETTING on ENABLE silently rewrites the bank you are using — leave it DISABLED unless that is what you want. Firmware: current is 2.51 (Nov 4, 2026); check it under SET UP → USER SETTING → FIRMWARE UPDATE.

Try it now

Do the steps now, in order, then save the setup to C1 and turn the dial away and back to prove it returns. Finish by checking the firmware — current is 2.51 — and confirming the clock and time zone.
