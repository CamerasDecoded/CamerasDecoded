First Setup

What should you change on a brand-new Fujifilm X-S20 before your first shoot?

https://camerasdecoded.com/camera-select/fujifilm/x-s20/first-setup.html
THE ANSWER
Format the one card in the camera, shoot FINE+RAW with LOSSLESS COMPRESSED RAW — the same data at about half the size — pick a film simulation on purpose, turn IS MODE on, then save the whole setup to C1 on the mode dial.
Format: SET UP → USER SETTING → FORMAT · RAW: IMAGE QUALITY SETTING → RAW RECORDING → LOSSLESS COMPRESSED · Film sim: IMAGE QUALITY SETTING → FILM SIMULATION · Save: IMAGE QUALITY SETTING → EDIT/SAVE CUSTOM SETTING → CUSTOM 1
Free lesson — the guided run walks every step.
STEP 1

One card, one job — format it first

MENU→SET UP→USER SETTING→FORMAT

Format the card in the camera before anything else. The X-S20 has one SD slot, UHS-II — no second slot, no in-camera backup, so the card is the shoot until it is copied to a computer. Video at the top 360 Mbps bit rate needs a card rated V60 or better; 100 and 200 Mbps get by on UHS Speed Class 3.

STEP 2

RAW, compressed without loss

MENU→IMAGE QUALITY SETTING→RAW RECORDING

Shoot FINE+RAW, and set RAW RECORDING to LOSSLESS COMPRESSED: Fujifilm’s reversible algorithm cuts files to about 30–90% of uncompressed size with no loss of image data. On a 64 GB card the manual’s table reads roughly 1,090 uncompressed RAW frames against 1,990 lossless. COMPRESSED is the lossy option — skip it.

STEP 3

Choose your palette on purpose

MENU→IMAGE QUALITY SETTING→FILM SIMULATION

Film simulation is the palette baked into every JPEG and HEIF: PROVIA/STANDARD is the neutral reference; Velvia, CLASSIC CHROME, CLASSIC Neg., the PRO Neg. pair and ACROS cover most work. REALA ACE — faithful color, hard tonality — was added by firmware 3.00; if it is missing from your list, update the body. The Fn dial ships as a film-sim dial, so you can preview palettes without opening a menu. RAW files keep everything, so FINE+RAW shooters can re-decide later.

STEP 4

IS on — then bank it to C1

MENU→IMAGE QUALITY SETTING→EDIT/SAVE CUSTOM SETTING

Set IS MODE (SHOOTING SETTING) to CONTINUOUS or SHOOTING ONLY — the body is rated to 7.0 stops of compensation. Then save the whole configuration: EDIT/SAVE CUSTOM SETTING creates banks CUSTOM 1 through CUSTOM 4, recalled by turning the mode dial to C1–C4 — real dial positions on this body. AUTO UPDATE CUSTOM SETTING on ENABLE will silently rewrite the bank you are using — leave it DISABLED unless that is what you want.

TRY IT NOW

Format the card, set RAW RECORDING to LOSSLESS COMPRESSED, pick your default film simulation, confirm IS MODE is on, and save it all as CUSTOM 1.
