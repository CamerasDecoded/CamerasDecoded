Custom buttons, your way

Which custom button setup is right for the Fujifilm X100VI?

camerasdecoded.com/camera-select/fujifilm/x100vi/custom-buttons
The answer — share this
Fn1 already toggles FACE DETECTION ON/OFF from the factory — put SUBJECT DETECTION ON/OFF on the front Fn2 and the people-or-animals swap is one press each way, because the two systems switch each other off anyway. The viewfinder selector’s rotate-and-hold is the factory ND FILTER switch. Give the control ring FILM SIMULATION or the digital teleconverter — and switch TOUCH FUNCTION on before expecting the flick gestures to do anything.
Path: SET UP → BUTTON/DIAL SETTING → FUNCTION (Fn) SETTING  ·  Fn1: FACE DETECTION ON/OFF (factory)  ·  Fn2: SUBJECT DETECTION ON/OFF  ·  Selector rotate-and-hold: ND FILTER (factory)  ·  Control ring: SET UP → BUTTON/DIAL SETTING → CONTROL RING SETTING → FILM SIMULATION

The Bench

What the factory already got right

MENU→SET UP→BUTTON/DIAL SETTING→FUNCTION (Fn) SETTING

All roles are chosen at FUNCTION (Fn) SETTING. The factory map: Fn1 (top plate) toggles FACE DETECTION ON/OFF — it also carries a separate playback role, set at Fn1 BUTTON SETTING; Fn2 (front of the body, beside the lens) is the control-ring options button; AEL/AFL locks exposure and focus; the center of the rear command dial is FOCUS CHECK; the Q button opens the quick menu; and rotating-and-holding the viewfinder selector toggles the ND FILTER. There is no view-mode button on this body — view modes are menu and eye sensor only.

The Map

One press each way

MENU→SET UP→BUTTON/DIAL SETTING→CONTROL RING SETTING

Keep Fn1 → FACE DETECTION ON/OFF and assign Fn2 → SUBJECT DETECTION ON/OFF: since the two detection systems switch each other off anyway, the people-or-animals swap becomes one press in either direction. The control ring’s jobs are STANDARD, WHITE BALANCE, FILM SIMULATION, DIGITAL TELE-CONV. or OFF — under STANDARD in P/S/A/M it runs the digital teleconverter. Hard rule: with the focus mode selector at M, the control ring works only for manual focus, whatever is assigned.

Dials, Lever, Glass

Handing jobs to the command dials

MENU→SET UP→BUTTON/DIAL SETTING→COMMAND DIAL SETTING

COMMAND DIAL SETTING assigns FRONT COMMAND DIAL 1/2/3 and REAR COMMAND DIAL among S.S. (PROGRAM SHIFT), APERTURE, EXP. COMPENSATION, ISO or NONE — with physical conditions: aperture-by-dial requires APERTURE RING SETTING (A) = COMMAND, compensation-by-dial requires the comp dial at C, ISO-by-dial requires the sensitivity dial at C. FOCUS LEVER SETTING dresses the stick’s center press (EDIT FOCUS AREA / ZOOM / RESET TO CENTER). The touch flicks T-Fn1–4 ship as HISTOGRAM / FILM SIMULATION / WHITE BALANCE / ELECTRONIC LEVEL SWITCH — and ship disabled, until TOUCH FUNCTION is set to ON.

Try it now

Assign Fn2 to SUBJECT DETECTION ON/OFF, give the control ring FILM SIMULATION, switch TOUCH FUNCTION on, and shoot ten minutes without opening a menu.
