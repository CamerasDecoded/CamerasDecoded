Custom Buttons

Which buttons should you customize on the Fujifilm X-T50, and what belongs on each one?

https://camerasdecoded.com/camera-select/fujifilm/x-t50/custom-buttons.html
THE ANSWER
Two Fn buttons, a focus stick, and dials that already do the work — so every assignment counts. Fn1 already toggles face detection; put SUBJECT DETECTION ON/OFF on Fn2, because the menu buries the swap you make most.
Assign: hold DISP/BACK, or BUTTON/DIAL SETTING → FUNCTION (Fn) SETTING · Touch: BUTTON/DIAL SETTING → TOUCH SCREEN SETTING → TOUCH FUNCTION SETTING · Save: IMAGE QUALITY SETTING → EDIT/SAVE CUSTOM SETTING → CUSTOM 1
Pro lesson — the deep steps are in the guided run.
STEP 1

Know the factory map first

MENU→BUTTON/DIAL SETTING→FUNCTION (Fn) SETTING

Two Fn buttons, not one: Fn1 on the front ships as FACE DETECTION ON/OFF, Fn2 on the back as FILM SIMULATION. AFON is autofocus, AEL locks exposure only, the rear dial’s center is FOCUS CHECK, Q opens the quick menu. There is no D-pad — the focus stick moves the focus point. Press and hold DISP/BACK to reassign any of them.

STEP 2

Build the detection swap

MENU→BUTTON/DIAL SETTING→FUNCTION (Fn) SETTING

Subject detection and face/eye detection switch each other off in both directions, so the toggle between them is the one you reach for mid-shoot. Fn1 already toggles face detection — put SUBJECT DETECTION ON/OFF on Fn2 and the swap is one press either way, no menu.

STEP 3

Two more that earn their place

MENU→BUTTON/DIAL SETTING→FUNCTION (Fn) SETTING

Video shooters: IS MODE BOOST, HIGH SPEED REC, F-Log VIEW ASSIST. Action shooters: PRE-SHOT ES and SPORTS FINDER MODE. RECALL CUSTOM 1 SETTING temporarily recalls the C1 bank while held. And the touch gestures — flick up for the histogram, down for AF MODE — are disabled by default; turn them on in TOUCH FUNCTION SETTING if you want them.

STEP 4

What the map survives

MENU→IMAGE QUALITY SETTING→EDIT/SAVE CUSTOM SETTING

The dials already carry the load: the shutter-speed dial and aperture ring set exposure, the film simulation dial sets the palette, the Auto lever switches between auto and manual. Save the whole map with EDIT/SAVE CUSTOM SETTING to CUSTOM 1–7, recalled from the menu — there are no C positions on any dial. Leave AUTO UPDATE CUSTOM SETTING DISABLED, or casual changes rewrite the bank you are standing in.

TRY IT NOW

Hold DISP/BACK, put SUBJECT DETECTION ON/OFF on Fn2, and save the map to CUSTOM 1.
