First Setup

What should you change on a brand-new Fujifilm X-T50 before your first shoot?

https://camerasdecoded.com/camera-select/fujifilm/x-t50/first-setup.html
THE ANSWER
Format the one card in the camera, shoot FINE+RAW with LOSSLESS COMPRESSED RAW — the same data at about half the size — pick a film simulation on the dial on purpose, turn IS MODE on, then save the whole setup to C1 in the menu.
Format: SET UP → USER SETTING → FORMAT · RAW: IMAGE QUALITY SETTING → RAW RECORDING → LOSSLESS COMPRESSED · Film sim: the dial on top (C for menu control) · Save: IMAGE QUALITY SETTING → EDIT/SAVE CUSTOM SETTING → CUSTOM 1
Free lesson — the guided run walks every step.
STEP 1

One card, one job — format it first

MENU→SET UP→USER SETTING→FORMAT

Format the card in the camera before anything else. The X-T50 has one SD slot, UHS-II — no second slot, no in-camera backup, so the card is the shoot until it is copied to a computer. Video at the top 360 Mbps bit rate needs a card rated V60 or better; 100 and 200 Mbps get by on UHS Speed Class 3. And the 40-megapixel files are big — a 64 GB card holds about 730 uncompressed RAW frames, so the next step matters.

STEP 2

RAW, compressed without loss

MENU→IMAGE QUALITY SETTING→RAW RECORDING

Shoot FINE+RAW, and set RAW RECORDING to LOSSLESS COMPRESSED: Fujifilm’s reversible algorithm cuts files to about 30–90% of uncompressed size with no loss of image data. On a 64 GB card the manual’s table reads roughly 730 uncompressed RAW frames against 1,370 lossless. COMPRESSED is the lossy option — skip it.

STEP 3

The dial is the palette

MENU→IMAGE QUALITY SETTING→FILM SIMULATION

The film simulation dial on top of the camera is the palette: PROVIA, Velvia, ASTIA, CLASSIC CHROME, REALA ACE, CLASSIC Neg., NOSTALGIC Neg., ACROS, three user slots FS1–FS3, and C for Custom. Twenty simulations in Fujifilm’s count. The trap to learn now: the menu, Q menu, function buttons, and saved custom settings only choose the simulation when the dial is on C — a named dial position overrides them all. RAW files keep everything, so FINE+RAW shooters can re-decide later.

STEP 4

IS on — then bank it to C1

MENU→IMAGE QUALITY SETTING→EDIT/SAVE CUSTOM SETTING

Set IS MODE (SHOOTING SETTING) to CONTINUOUS or SHOOTING ONLY — the body is rated to 7.0 stops of compensation. Then save the whole configuration: EDIT/SAVE CUSTOM SETTING creates seven banks, CUSTOM 1 through CUSTOM 7, recalled from the menu — there are no C positions on any dial on this body. AUTO UPDATE CUSTOM SETTING on ENABLE will silently rewrite the bank you are using — leave it DISABLED unless that is what you want.

TRY IT NOW

Format the card, set RAW RECORDING to LOSSLESS COMPRESSED, turn the film simulation dial to your default palette, confirm IS MODE is on, and save it all as CUSTOM 1.
