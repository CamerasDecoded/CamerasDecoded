Custom button map

Which functions belong on the Panasonic Lumix S5 II's buttons — a joystick that is five Fn buttons, cursor keys that are four more, and roles other systems don't offer?

camerasdecoded.com/camera-select/lumix/s5-ii/custom-buttons
The answer — share this
Open Custom Menu (Operation) → Fn Button Set → Setting in REC mode and build the map around this body's own roles: Detecting Subject and AF Detection Setting for focus, Destination Card Slot to flip the recording card, E-Stabilization (Video) and REAL TIME LUT for video — on a surface that includes five joystick presses and four cursor keys most owners never learn are buttons.
Path: Custom Menu (Operation) → Fn Button Set  ·  Joystick presses: Fn12–Fn16  ·  Cursor keys: Fn8–Fn11  ·  The Delete button is Fn1
Cameras Decoded — Camera Select
Step 1

Fn Button Set

MENU→Custom Menu (Operation)→Fn Button Set

Fn Button Set holds two assignment maps: Setting in REC mode and Setting in PLAY mode — a button can do different work while recording and while reviewing. Lens Fn Button Setting separately assigns the focus button on lenses that carry one; its role list includes Focus Stop, AF Mode, AF Detection Setting, Detecting Subject, AF-ON, AF-ON: Near Shift / Far Shift, Image Stabilizer and Preview.

Step 2

Count the surface

MENU→Custom Menu (Operation)→Fn Button Set

The assignable surface is larger than the labels suggest. Per the manual's parts list, the joystick's directions and center press are Fn12–Fn16, the four cursor keys are Fn8–Fn11, and the Cancel/Delete button is Fn1. Add the front Fn buttons and the lens button, plus Q.MENU Settings, which rebuilds the Quick Menu — firmware Ver. 3.0 added Proxy Recording and E-Stabilization (Video) to both the Fn list and the Quick Menu.

Step 3

The working map

MENU→Custom Menu (Operation)→Fn Button Set→Setting in REC mode

Build around this body's signature roles. Detecting Subject and AF Detection Setting put focus intelligence on a press. Destination Card Slot is the Fn role Panasonic names for switching which card Relay Rec prioritizes. E-Stabilization (Video) toggles the electronic stabilizer between locked and moving shots. REAL TIME LUT has been assignable to an Fn button since firmware Ver. 3.1. Save to Custom Mode assigned to a button registers the current camera state to the mode dial without opening a menu.

Step 4

Dials, Quick Menu, save

MENU→Custom Menu (Operation)→Dial Operation Switch Setup

Dial Operation Switch Setup assigns a button that temporarily swaps the roles of the front and rear dials. Q.MENU Settings customizes the Quick Menu's items for photo and video separately. When the map is built, register a Custom mode so the control scheme — buttons included — is recalled with the mode dial and survives a settings reset.

Try it now

Build the map now — detection, card-slot switch, stabilizer, baked look — press every assigned button once to prove it, then register the whole scheme to a Custom mode.
