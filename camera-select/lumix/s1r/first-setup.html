First Setup

What should you change on a brand-new Panasonic Lumix S1R before your first shoot — firmware, cards, backup and files, set once and saved?

https://camerasdecoded.com/camera-select/lumix/s1r/first-setup.html
THE ANSWER
Update the firmware to Ver. 2.1 first — a camera on fw 1.0 will not even see a CFexpress card — format both cards in the camera, set slot 2 as the backup, shoot RAW+FINE, and save the whole setup to C1 on the mode dial.
Firmware: Setup (Others) → Firmware Version · Cards: Setup (Card/File) → Card Format · Backup: Setup (Card/File) → Double Card Slot Function → Backup Rec · File: Photo (Image Quality) → Picture Quality → RAW+FINE · Save: Setup (Setting) → Save to Custom Mode → C1
Free lesson — the guided run walks every step.
STEP 1

Update the firmware first

MENU→Setup Menu (Others)→Firmware Version

Check the firmware before anything else. S1R bodies were still shipping on fw 1.0 in 2025, and fw 1.0 does not support CFexpress cards at all — the fast card in slot 1 simply will not work until the camera is updated. Current firmware is Ver. 2.1 (January 23, 2025). CFexpress support arrived in Ver. 1.3, the 6.0-stop stabilizer in Ver. 1.2, and the 5K video modes in Ver. 1.6 — every one of those is a firmware update, not a purchase. Download the update from Panasonic support, copy it to a formatted card, and run it from the menu.

STEP 2

Two slots, two jobs — format both, set the backup

MENU→Setup Menu (Card/File)→Double Card Slot Function

Slot 1 takes XQD or CFexpress Type B; slot 2 takes SD only — the two slots are not interchangeable. Format both cards in the camera before the first shoot. Then set Double Card Slot Function: Backup Rec writes every frame to both cards at once, Relay Rec rolls to slot 2 when slot 1 fills, Allocation Rec splits by type — RAW to one card, JPEG to the other, video to its own. Backup Rec wants same-capacity cards, and some card combinations block video and 6K/4K Photo entirely. One more rule to know now: AVCHD video cannot be recorded to slot 1 at all.

STEP 3

The honest file — and the 47-megapixel math

MENU→Photo Menu (Image Quality)→Picture Quality

Set Picture Quality to RAW+FINE: every frame carries a finished JPEG and the full RAW data. Then do the card math, because 47.3 megapixels makes big files — the manual’s own table puts about 680 RAW+FINE frames on a 64 GB card, against 2,640 FINE JPEGs. A 128 GB card roughly doubles both numbers. Picture Size ships at L (46.5M); leave it there unless you have a reason to shrink. And the SD card in slot 2 needs to be fast for more than stills: 4K video, 6K/4K Photo, and Post-Focus all need a card rated UHS Speed Class 3, V30 or higher.

STEP 4

Stabilizer on — then bank it to C1

MENU→Setup Menu (Setting)→Save to Custom Mode

Confirm Image Stabilizer is on with Operation Mode set to Normal — the body is rated to 6.0 stops, and 6.5 stops as Dual I.S.2 with the 24-105mm kit lens. Then save everything you just built: Save to Custom Mode stores the whole configuration to C1, C2, or C3 on the mode dial. C3 is the deep one — it holds up to 10 sets, three by default. At purchase every Custom mode holds the P-mode defaults, so saving now is what makes C1 yours. Temporary changes never overwrite a saved bank; re-save to change it.

TRY IT NOW

Check the firmware version, format both cards, set Double Card Slot Function to Backup Rec, set Picture Quality to RAW+FINE, and save it all to C1.
