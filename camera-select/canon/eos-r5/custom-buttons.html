Custom button map

Which functions belong on the R5's buttons?

https://camerasdecoded.com/camera-select/canon/eos-r5/custom-buttons.html

THE ANSWER, UP FRONT

The multi-controller keeps Direct AF point selection — on this body it is the only control that can hold it. M-Fn switches the AF method directly (and can even jump you to a Custom shooting mode in one press), and the AE lock button jumps straight to the eye.

Assign: Custom Functions → Customize buttons · Multi-controller: Direct AF point selection · M-Fn: Direct AF method selection · AE lock: Eye Detection AF · Quick control dial: Select AF method (Customize dials) · Save: register to C1

Deep steps are Pro
The map

Buttons on one desk, dials on another

MENU→Custom Functions→Customize buttons

Canon splits the job: Customize buttons for the buttons, Customize dials beside it for the dials and the lens control ring. The same button can carry a different function for stills and for movies — build both sets. Multi-controller: Direct AF point selection. M-Fn: Direct AF method selection. AE lock button: Eye Detection AF.

Assignment 1

The stick, kept

Direct AF point selection is the multi-controller’s work — nudge the stick and the point moves. On this body Canon’s table gives that function to the multi-controller and no other control, so the map keeps it there and assigns everything else to controls that can hold it.

Assignment 2

M-Fn — Direct AF method selection

MENU→Custom Functions→Customize buttons

The method change is the most common mid-shoot move there is: Face+Tracking to Zone to Spot. On the M-Fn button it costs one press and a dial turn, eye still to the viewfinder. The Quick control dial can also take Select AF method from the Customize dials desk. And M-Fn alone can hold Switch to Custom shooting mode — one press into a C-mode setup.

Assignment 3

AE lock — Eye Detection AF

MENU→AF→Eye detection

Eye Detection AF jumps focus straight to the subject’s eye. On this body it can only live on AF-ON, the AE lock button, the AF point button, the depth-of-field preview button, or a lens button — the AE lock button is its natural home. Know the other absence: there is no Direct select of subject to detect function here; the subject is named in the AF menu, not on a button.

Save it

The map lives in C1 — and on a card

MENU→Set-up→Custom shooting mode (C1-C3)→Register settings

A C1 registration captures shooting, menu and Custom Function settings — the button map included. Register the finished map to C1, and the mode dial restores your settings and your buttons together. Save/load cam settings on card can also write the whole arrangement to a file, loadable on another EOS R5.

Try it now: Set M-Fn to Direct AF method selection, then practice switching between Face+Tracking and Zone on a person and a group before adding the rest of the map.
