Common fixes

What fixes the R6 II's known problems — one-card recordings, focus breathing, the wrong subject, manual lenses?

camerasdecoded.com/camera-select/canon/eos-r6-ii/common-fixes
The answer — share this
Only one card filled: Rec. to multiple was never set. Breathing: Focus breathing correction, with Distortion correction on first. Wrong subject: Subject to detect. Manual lens: set its focal length, and let the shutter release without a lens.
Backup: Set-up → Record func+card/folder sel. → Rec. to multiple · Breathing: Shooting → Lens aberration correction → Focus breathing correction · Subject: AF → Subject to detect · Manual lens: Shooting → IS mode → Focal length
Cameras Decoded — Camera Select
Everything landed on one cardRec. to multiple. MENU → Set-up → Record func+card/folder sel. → Rec options. Standard is the default — one card records, the other waits. Multiple writes every still to both cards at once.
Frame pulses when focus racksFocus breathing correction. MENU → Shooting → Lens aberration correction. The item appears only when Distortion correction is set to Enable, and it is a movie-only correction that narrows the angle of view slightly.
Focus locks the wrong subjectCheck Subject to detect. MENU → AF → Subject to detect. A subject left over from the last shoot is the usual cause. For portraits, set Eye detection to the near eye.
Manual lens: dead shutter, blind ISRelease shutter w/o lens + Focal length. Custom Functions → Release shutter w/o lens → Enable, so the shutter fires with a contactless lens. Then Shooting → IS (Image Stabilizer) mode → Focal length: set the lens's focal length (1–1000mm) so stabilization is tuned to it.
