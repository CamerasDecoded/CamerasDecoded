First Setup

What should you change on a brand-new Nikon Z fc before your first shoot — one SD slot that takes UHS-I only, RAW at 14 bits with a 36-frame buffer, and dials that are the memory because there is no U1 to save to?

The answer — share this
Format the one SD card in the camera, shoot NEF (RAW) + JPEG fine with RAW recording at 14 bits, set lens Vibration reduction to Normal, and check the firmware is C 1.81 — this body keeps no second card, no in-body stabilization and no U1 to save to, so your backup and your steadiness are habits, and the dials are the memory.
Format: Setup Menu → Format memory card  ·  RAW recording: 14-bit (24.4 MB, buffer 36)  ·  Vibration reduction: Normal — lens VR only, no IBIS on this body  ·  Firmware: Setup Menu → Firmware version → C 1.81  ·  Cards: ONE SD slot, UHS-I only — no backup recording
Cameras Decoded — Camera Select
Step 1

Format the card in the camera

MENU→Setup Menu→Format memory card

Formatting builds the folder structure the camera expects and clears a card that has lived in other devices. This body has one memory card slot, reached through the shared battery-chamber cover, and it takes SD, SDHC and SDXC cards — UHS-I only. The faster UHS-II cards still work, but they run at UHS-I speed, so do not pay the premium for this body. While you are in the Setup Menu, set the clock too — Time zone and date sits in the same tab. And build the house rule now: one card, one copy — with no second slot and no backup recording, the copy you make at the computer after every shoot that matters is the only backup there is. Formatting permanently deletes everything on the card, so empty it first.

Step 2

NEF + JPEG fine, at 14 bits

MENU→Photo Shooting Menu→Image quality
MENU→Photo Shooting Menu→RAW recording

Set Image quality to NEF (RAW) + JPEG fine — the RAW for the edit, the JPEG for sharing straight from the camera. Then choose the depth: RAW recording offers 12-bit or 14-bit. 14-bit holds more color data and costs more: a large RAW file is about 24.4 megabytes and the buffer runs to 36 frames. 12-bit is about 19.4 megabytes with a 44-frame buffer. For most shooting, 14-bit is the right default — the extra color data is what saves a sky or a skin tone in the edit. Switch to 12-bit only when you are shooting long bursts and the buffer matters more than the last bit of color. JPEG fine on its own is about 9.5 megabytes a file, with an 83-frame buffer.

Step 3

Lens VR — because the body has none

MENU→Photo Shooting Menu→Vibration reduction

This body has no in-body stabilization. The Vibration reduction item in the Photo Shooting Menu drives the lens — and the manual says it plainly: the options available vary with the lens, and vibration reduction may be unavailable with some lenses. Set it to Normal for everyday shooting; Sport steadies the viewfinder image for a moving subject and for panning. The honest consequence: with a lens that has no VR of its own, there is no stabilization at all — your shutter speed and your stance are doing the work. The kit 16-50mm has VR; the 28mm f/2.8 SE and 40mm f/2 SE primes do not.

Step 4

The dials are the memory

MENU→Setup Menu→Firmware version

There is no U1 to save a setup to — the dials remember by position. The shutter-speed dial runs 1/4000 to 4 seconds in full stops, plus Bulb, Time and X — and the 1/3STEP position hands shutter speed to the main command dial in 1/3-stop steps, down to 30 seconds (900 seconds in M with Custom Setting d5 on). A lock release must be pressed to select X or T, or to leave 1/3STEP. The exposure compensation dial runs -3 to +3 EV — but set it to [C] and the range opens to -5 to +5 EV, adjusted by the command dial, the i menu, or the lens control ring. Check the firmware while you are here: Setup Menu → Firmware version should read C 1.81 (June 2026). The 1.81 update fixed a monitor that could stay blank with Prioritize viewfinder selected, and 1.50 added support for the longer-lasting EN-EL25a battery.

Step 5

Know the body you bought

A 20.9-megapixel DX CMOS sensor with the EXPEED 6 engine, 209 focus points across 87% of the frame, a 0.39-inch 2360k-dot OLED viewfinder and a 3-inch vari-angle touch screen that flips forward for self-portraits. No built-in flash — the hot shoe takes an optional flash unit. Battery life is CIPA-rated at about 360 shots with the EN-EL25a (viewfinder) — carry a spare, and charge over USB-C when you can.

Try it now

Format the card, set the clock, NEF plus JPEG fine at 14 bits, lens VR on Normal — then check the firmware reads C 1.81. Turn the shutter-speed dial to 1/3STEP and roll the command dial to feel the 1/3-stop steps. Copy the card when you get home: that copy is your backup now.
